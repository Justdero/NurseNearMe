## ✨ What is NurseNearMe?

**NurseNearMe** is a worldwide platform where anyone can hire a **verified private nurse** nearest to them.

> Like Uber, but for Nurses.

Patients search by location, see verified nurses, book, pay via **M-Pesa / Card / PayPal**, and chat on **WhatsApp**.

Nurses join **FREE** and keep **90%** of earnings. NurseNearMe takes only **10% commission**.
